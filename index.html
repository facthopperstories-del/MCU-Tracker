    Settings

    Everything is stored on this device, and optionally synced to your own GitHub.

    Sync phone ↔ PC

    Log in once on each device and progress syncs by itself — no more export codes. It's saved to a private file (a “secret gist”) in your own GitHub account.

    How to get a token (2 min)
    1. On github.com open Settings → Developer settings → Personal access tokens → Tokens (classic).
    2. Generate new token (classic). Note: “Sacred Timeline”. Expiration: No expiration (or 1 year).
    3. Tick only the gist box. Nothing else.
    4. Generate, copy the token, paste it here. Do the same paste on your other device.

    The token can only read/write your gists. It stays in this browser's storage and is never in the page's code.
